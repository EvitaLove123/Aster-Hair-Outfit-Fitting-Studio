2. Select part to adjust

Use the 3D gizmo to move, rotate, or scale the selected slot. Dragging the gizmo temporarily disables camera orbit.

3. Delete character meshes

Removes the selected mesh from the base model, for example old hair or body parts hidden by an outfit. Undo restores the last deleted mesh.

4. VRoid custom item

A valid .vroidcustomitem requires VRoid Studio's own item data (parameters, texture layers, category and version). A generic VRM/GLB mesh cannot be packaged into a valid custom item here. Use VRoid Studio to create/export this format.

5. Current limits

  • Preview and manual positioning for VRM / GLB.
  • Export combines visible scene objects into GLB.
  • VRM export is available when the Base Character is a VRM; GLB-only base models cannot be converted into VRM by this exporter.
  • Accessory meshes are included as scene objects, but are not automatically skinned or retargeted to the base skeleton.
  • .vroidcustomitem export is not supported because it requires VRoid Studio item data.
  • No UniVRM dependency and no fabricated UniVRM metadata.
